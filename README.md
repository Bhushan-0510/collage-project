# ARMS - Academic Resource Management System
## Modern Education Software Website

### Project Overview
This is a completely redesigned, modern website for the Academic Resource Management System (ARMS) of the M.Com in Computer Management (MCM) department at L.R.T Commerce College, Akola.

### Features Implemented

#### 🎨 Modern Design Elements
- **Parallax Scrolling**: Smooth parallax effects on hero sections
- **Glassmorphism Cards**: Contemporary glass-effect cards with backdrop blur
- **Gradient Backgrounds**: Modern gradient color schemes throughout
- **Smooth Animations**: Scroll-reveal animations with Intersection Observer API
- **Floating Particles**: Animated background particles for visual interest
- **3D Card Tilt**: Interactive 3D tilt effect on hover
- **Custom Cursor**: Modern cursor follow effect (desktop only)

#### 🎯 Modern UX/UI Features
- **Responsive Navigation**: Mobile-friendly hamburger menu
- **Scroll Animations**: Elements fade in as you scroll
- **Smooth Scrolling**: Native smooth scroll behavior
- **Back to Top Button**: Convenient navigation
- **Form Validation**: Real-time input validation
- **Notification System**: Toast-style notifications
- **Active Link Highlighting**: Auto-highlight active nav items

#### 🎓 Education-Focused Design
- **Professional Color Palette**: Purple/indigo gradients for academic feel
- **Clean Typography**: Inter & Poppins fonts for readability
- **Organized Layout**: Clear information hierarchy
- **Accessibility**: ARIA labels and keyboard navigation support

### How to Use

1. **Local Development**
   - Open `index.html` in a web browser
   - All pages are linked and functional
   - No build process required

2. **Deployment**
   - Upload all files to web server
   - Maintain folder structure
   - Ensure file paths are correct

3. **Customization**
   - Colors: Edit CSS variables in `:root`
   - Content: Update HTML files
   - Animations: Modify `main.js`
