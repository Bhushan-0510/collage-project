Installation Guide

Install in 3 Simple Steps

Since ARMS is distributed directly (not via Play Store), you'll need to allow installation from unknown sources. It's quick and safe.

1
Download the APK

Tap the "Download APK" button on this page. The file will download directly to your Android phone's storage.

2
Allow Unknown Sources

When prompted, go to Settings → Security → Install Unknown Apps and allow your browser to install APKs.

3
Login & Access ARMS

Open the app, log in with your institutional credentials, and start accessing your academic resources instantly.

⚠️
Important Security Note

You may see a warning from Android when installing from outside the Play Store — this is normal for direct APK installs. The ARMS APK is safe and officially distributed by your institution. After installation, you can re-disable "Unknown Sources" in your settings for added security.
